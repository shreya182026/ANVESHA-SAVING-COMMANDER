# Daily Money + Calendar data update

The project now includes a reusable daily money model:
- Multiple income entries per date.
- Multiple expense entries per date.
- Per-day totals and net amount.
- Historical date lookup.
- Monthly aggregation for monthly review.
- Records use YYYY-MM-DD keys so calendar dates remain stable.
- A reusable DailyMoneySummary UI component.
- No automatic money transfer is triggered by recording income.
